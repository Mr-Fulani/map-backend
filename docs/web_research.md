# Интернет-исследование товаров

Интернет-исследование дополняет данные каталогов внешними источниками. Оно запускается
автоматически после Tachka/Rossko, если полнота данных ниже
`WEB_RESEARCH_COVERAGE_THRESHOLD`. Все полученные из открытого интернета факты требуют
ручной проверки.

## Подключение поискового сервиса

Платформенные подключения доступны только суперпользователю:

1. Откройте **AI-агент → Сервисы интернет-поиска**.
2. Создайте подключение и выберите `brave` или `tavily`.
3. Введите API-ключ, выберите роль **Основной** или **Резервный** и задайте ограничения.
4. Сохраните подключение.
5. Выберите его в списке и выполните действие **Проверить выбранные подключения**.

API-ключ сохраняется в `credentials_enc`, зашифрованном Fernet-ключом
`FIELD_ENCRYPTION_KEY`. После сохранения ключ не отображается и не возвращается через
tenant API.

Если запись подключения для провайдера ещё не создана, сохраняется обратная
совместимость с серверными переменными:

- `BRAVE_SEARCH_API_KEY`;
- `TAVILY_API_KEY`.

Как только для провайдера создана запись, она становится единственным источником его
активности, приоритетов и тарифной политики. Отключённая запись отключает и legacy
fallback из окружения.

## Маршрутизация

В админке одному подключению назначается роль **Основной**, остальным — **Резервный**.
Основной вызывается первым. При назначении нового основного предыдущий автоматически
становится резервным. В базе роли сохраняются как приоритеты `10` и `20`, после чего
маршрутизатор исключает:

- отключённые подключения;
- провайдеры без установленного адаптера;
- подключения, недоступные тарифу тенанта;
- подключения, исчерпавшие минутный или месячный лимит.

При сетевой ошибке, HTTP 429/5xx или пустой выдаче запрос передаётся следующему
подключению. Исследование завершается ошибкой только после исчерпания всех доступных
вариантов. Каждое обращение сохраняется как `WebSearchAttempt` с провайдером, запросом,
статусом, длительностью и безопасным текстом ошибки.

## Параметры

Безопасные настройки можно передать через JSON-поле `parameters`.

Brave:

```json
{
  "country": "ru",
  "search_lang": "ru",
  "extra_snippets": true,
  "timeout": 15
}
```

Tavily:

```json
{
  "search_depth": "basic",
  "include_raw_content": true,
  "include_domains": [],
  "exclude_domains": [],
  "timeout": 20
}
```

Пустой `allowed_plan_slugs` разрешает подключение всем тарифам. Тарифные правила можно
включать постепенно без изменения адаптеров и бизнес-логики исследования.

## Пользовательский сценарий

В карточке товара основной сценарий — **Обогатить и сгенерировать**. Отдельного
первичного запуска интернет-поиска нет. После завершённого, неудачного или пустого
исследования в его блоке появляется **Повторить интернет-поиск**.

Раздел tenant dashboard **Интернет-поиск** показывает общий журнал и доступные сервисы.
Тенант не видит ключи и не выбирает платформенное подключение напрямую: по умолчанию
используется безопасный автоматический режим.
