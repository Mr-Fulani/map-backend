# AI-промпты и оценка качества

## Где применяются промпты

- Поиск изображений использует детерминированный `Search Query v3`, а не LLM.
- Генерация описаний выбирает активный `AIPromptTemplate` по задаче, домену
  каталога и маркетплейсу. При отсутствии записи используется безопасный шаблон из кода.
- Генеративная обработка медиа получает контролируемый сервером prompt; пользователь
  выбирает только разрешённый стиль фона.

## Версии и откат

Существующую версию промпта не следует редактировать. В админке создаётся новая запись
с увеличенным `version`, после чего действие «Активировать выбранную версию промпта»
атомарно отключает предыдущую версию того же scope. Каждый `AIRequestLog` сохраняет
ссылку на шаблон, version и SHA-256 фактического system prompt.

Scope разрешается в порядке:

1. точный домен + маркетплейс;
2. точный домен + любой маркетплейс;
3. любой домен + точный маркетплейс;
4. глобальный шаблон.

## Безопасность и повторные попытки

Данные товара передаются JSON-конвертом и объявлены недоверенными данными. Команды из
названий или описаний 1С не должны интерпретироваться как инструкции. Если валидатор
отклоняет результат, следующая попытка получает конкретную причину ошибки. Для OpenAI
Responses API дополнительно передаётся JSON Schema; остальные адаптеры продолжают
работать через единый JSON-контракт и серверный валидатор.

Подтверждённая применяемость передаётся структурированным массивом `trusted_fitments`:
марка, модель, поколение, годы, модификация, код двигателя и мощность. Если массив не
пуст, описание обязано перечислить все пары «марка + модель». Неполный ответ отклоняется
сервером, а модель получает список пропущенных автомобилей при повторной попытке.

Ручное подтверждение применяемости обучает глобальный граф знаний по связке
`бренд + артикул`. После этого подтверждённые автомобили могут автоматически применяться
к такому же товару другого тенанта; отклонённые и спорные связи граф не обучают.

Итоговый `confidence` вычисляется сервером по полноте проверенных исходных данных.
Самооценка модели сохраняется отдельно как `model_confidence` и не считается доказательством.

## Offline eval

`apps.ai_agent.evals.description` содержит 50 эталонных автозапчастей и сравнивает
старые/новые результаты по длине, обязательным идентификаторам и запрещённым фразам.
Eval не вызывает платные API в тестах. Для реального A/B прогона результаты двух версий
следует собрать во внешнем задании и передать в `compare_prompt_results`.

Новая версия не должна активироваться, если её pass rate или средний score хуже текущей.
