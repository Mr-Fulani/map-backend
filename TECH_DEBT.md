# Технический долг MAP

Обновлено: 2026-08-29.

Этот файл содержит только подтверждённые остаточные риски и критерии их
закрытия. Продуктовые функции перечислены отдельно и не должны подаваться как
ошибки работающей платформы.

## Не является техническим долгом

Это отдельные продуктовые направления:

- Ozon и provider-neutral разделение интерфейса — следующий основной roadmap:
  [`docs/MARKETPLACE_EXPANSION_ROADMAP.md`](docs/MARKETPLACE_EXPANSION_ROADMAP.md);
- импорт объявлений, созданных вручную в Avito;
- смена оплаченного тарифа с proration/credit;
- исходящая почта с собственного домена тенанта;
- расширенные массовые действия над листингами;
- дополнительные источники enrichment.

## Правила

- Новая найденная проблема добавляется сюда только с доказательством и
  критерием закрытия.
- `CODE_READY` не означает, что изменение можно выкладывать без свежего CI.
- P7 нельзя объединять с Ozon, Billing или удалением legacy-кода.
- Cleanup/backfill, object GC и жёсткие DB-ограничения выпускаются раздельно.
- Закрытая строка удаляется из этого файла после переноса фактического evidence
  в профильный статус/runbook; этот файл не должен превращаться в исторический
  журнал.
